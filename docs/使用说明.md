# 蛋白钱包 · 使用说明(一页)

谢谢你帮忙试用。这是一个给生活费有限又想增肌的大学生记账 + 记营养的小工具,核心就一个数:**每一美元换到多少克蛋白质**。

## 1. 装到手机主屏(一次性)

- iPhone:Safari 打开链接 → 底部「分享」→「添加到主屏幕」。
- Android:Chrome 打开链接 → 右上角菜单 →「安装应用」或「添加到主屏幕」。

以后从主屏图标打开,像 App 一样用。

## 2. 第一次打开

两个问题:体重(可跳过,用来算每日蛋白目标,体重 × 1.6g)、每周饮食预算(先选美元还是人民币,含外食和买菜)。
以后都能在「设置」里改。吃食堂的话,顺手在「设置」里选一下**常去的食堂**(Baker / Bartlett / Woodlawn / Cathey),以后记一餐会默认选中。

## 3. 怎么记(目标:10 秒内)

首页点「+ 记一餐」,四种方式:

| 场景 | 怎么做 |
| --- | --- |
| 外面吃、有小票 | **拍餐厅小票**:一张照片同时记钱和记餐。拼单的话,把不是你吃的那几项删掉再保存 |
| 食堂、没小票 | 先在上面点一下是哪个食堂,再**拍餐食**:会按食堂官方菜单的每份营养来算,比纯目测准得多。金额手动补一下(设置里可以给食堂刷卡设个默认价) |
| 懒得拍、懒得打字 | **说一句**:按黑色麦克风按钮,说「Chipotle 鸡肉碗 11 块 5」,松开就解析;或者直接打一句 |
| 自己做饭 | 买菜时**拍买菜小票**(只记钱,不记营养);吃的时候给做好的菜**拍餐食** |

AI 解析完会给一张确认卡,**任何字段都可以点开改**,改完「确认保存」。改动会被记录下来,这是我改进识别的最重要数据,所以看到不对就改,别将就。

## 4. 看懂数字

- 营养永远是**区间**,比如「蛋白 45–55 g」,不会给你一个假精确的单一数。
- **实线绿框 + 官方数据**:Chipotle、麦当劳、Shake Shack、Sweetgreen、KFC 这几家,每一行都对过官网,比较准。
- **虚线框 + 食堂菜单**:选了食堂之后,每道菜的营养是食堂官方的,但一勺还是两勺是看图估的,所以区间中等。看到份数不对就改。
- **虚线框 + 参考数据·未核实**:其他连锁(Subway、Panda Express 等),数据还没逐行核实过,先当参考。
- **虚线框 + 目测估算**:中餐、家常菜、没选食堂的餐盘,是看图估的,区间最宽。
- 首页两个数:今天蛋白还差多少、本周预算还剩多少。只陈述事实,不会告诉你该吃什么。
- **¢/g** = 这份食物每克蛋白质花了多少美分,越低越划算。周报里有你自己的排行榜。

## 5. 周报

底部「周报」:本周花销 vs 预算、蛋白达标天数、蛋白质单价排行榜、和上周的变化。可以往前翻。

## 6. 每周帮我做一件事

周日打开「设置」→「导出 JSON」,把文件发给我。里面只有你的记录和设置,没有照片。
这也是你的备份:数据只存在你手机浏览器里,**不要清 Safari / Chrome 的网站数据**,换手机前先导出。

## 7. 识别失败怎么办

照片太糊、不是食物、小票读不出来,会提示重拍或改用文字输入,不会卡住。实在不行就一句话写上。

有任何觉得别扭的地方直接在群里说,越具体越好(哪一步、截图)。
