# 蛋白钱包 · 使用说明(一页)

谢谢你帮忙试用。这是一个给生活费有限又想增肌的大学生记账 + 记营养的小工具,核心就一个数:**每一块钱换到多少克蛋白质**。

## 1. 装到手机主屏(一次性)

- iPhone:Safari 打开链接 → 底部「分享」→「添加到主屏幕」。
- Android:Chrome 打开链接 → 右上角菜单 →「安装应用」或「添加到主屏幕」。

以后从主屏图标打开,像 App 一样用。

## 2. 第一次打开

两个问题:体重(可跳过,用来算每日蛋白目标,体重 × 1.6g)、每周饮食预算(元,含外食和买菜)。
第一次打开会先看到一份示例:13 张真实外卖订单解析出来的记录,可以看看首页和周报长什么样,随便点,不影响任何人。首页顶部点「开始用自己的」就进入上面这两个问题。之后想再看示例,在「设置 → 示例」里点「看示例」;示例和你自己的记录是分开存的。
以后都能在「设置」里改。食堂按菜计价,记的时候直接填这顿花了多少钱就行。

## 3. 常去的地方拍一次,以后每天打开就有清单

把你常去的窗口、小摊、外卖店的菜单各拍一次:首页点「拍菜单」,拍一下食堂窗口的价目牌、路边摊的招牌,或者选一张美团 / 饿了么店铺菜单的截图(也可以直接把菜名和价格打出来)。十几秒后会看到这张菜单按"每一块钱换多少克蛋白"排好的结果,同时它会自动存成一个"常去的地方",名字可以改。

**同学拍过的,你不用再拍。** 排序页上点「分享」,会生成一个链接,发到宿舍群里,别人点开选「存下来」,这个地方的菜单就到他手机上了。反过来,别人发给你的链接点开也一样。分享来的菜单价格可能已经变了,自己重拍一次那个地方就会更新。

**刚开始什么都没拍也有东西看。** 第一次打开时,首页会带一份「超市基础款」:鸡蛋、豆腐、鸡胸这些,价格是参考价。等你自己存的地方和记录够用了,它就不再出现在首页;不想要可以在「拍菜单」页点开它删掉。

**之后不用再拍。** 每天打开首页,「下一顿」卡片会把你存过的这些地方的菜和你自己记过的餐放在一起,挑出今天的钱够买的,按每块钱蛋白排好。点一样就记上。菜单变了、涨价了,再拍一次同一个地方就会更新。

- 这只是排序,不是推荐,吃什么你自己定。可以切换成"按每份蛋白"。
- 每行右边的小字是 分/g 的区间。菜单上看不到份量,数字是按菜名估的,区间越宽越没把握。
- 白米饭、凉皮、清炒时蔬这类只有主食或蔬菜的,还有没读到价格的,不参与排名,列在最下面。
- 点其中一样,确认一下就记上了,不用再单独记一次。读错了菜名或价格可以在确认卡上改。
- 想再看某个地方的整张菜单:「拍菜单」页上面有"存过的地方",点开直接看,不用重拍。不想要了就在那一页点「删除」。

## 4. 怎么记(目标:10 秒内)

首页点「+ 记一餐」,四种方式:

| 场景 | 怎么做 |
| --- | --- |
| 点外卖 | **拍外卖订单截图**(美团 / 饿了么订单页):菜名、单价、实付一次解析出来,同时记钱和记餐。用了红包、加了打包费的,每道菜会按你实际付的合计分摊,依据里写着"标价多少,按实付多少"。拼单的话,把不是你吃的那几项删掉再保存。有纸质小票也可以拍小票 |
| 食堂 | **拍餐食**,再填一下这顿花了多少钱(食堂按菜计价,看小票或记一下窗口价)。营养是看图估的,份量不对就点份量按钮改 |
| 懒得拍、懒得打字 | **说一句**:按黑色麦克风按钮,说「食堂红烧鸡腿加米饭 12 块」,松开就解析;或者直接打一句 |
| 自己做饭 | 买菜时**拍买菜小票**(只记钱,不记营养);吃的时候给做好的菜**拍餐食** |
| 喝蛋白粉 | 先在「设置」→「蛋白粉」照罐子上的标签填一次(每勺蛋白、整桶价格、整桶勺数),之后首页常吃那一排第一个就是「记一勺」,点一下就记上 |
| 一天只想记一次 | 首页点「**日结** · 睡前一句话记一天」,把今天吃的按顿写一句,用顿号分开、带上价格:"早饭鸡蛋牛奶 5 元、午饭食堂鸡腿饭 12 元、晚饭外卖黄焖鸡 22 元、一勺蛋白粉",会拆成一条一条,改完一起保存 |

AI 解析完会给一张确认卡,**任何字段都可以点开改**,改完「确认保存」。卡上有一排份量按钮(1 勺 / 2 勺 / 3 勺…),AI 对份量没把握时会标黄,点一下实际吃的量,热量和蛋白质自动按比例改,这比手改数字快。
保存后会先看到两句话:这顿多少分/g、在本周排第几;今天还差多少克、约等于你自己记过的最便宜的东西几份、多少钱。只是把差额换算成你吃过的东西,不是让你去吃什么。
保存以后在首页点那条记录还能改。首页最上面一排「常吃」是你最近 30 天记得最多的 5 样,点一下就记上,今天已记过的不会出现。改动会被记录下来,这是我改进识别的最重要数据,所以看到不对就改,别将就。

## 5. 看懂数字

- 营养永远是**区间**,比如「蛋白 45–55 g」,不会给你一个假精确的单一数。
- **实线绿框 + 官方数据**:逐行对过官网营养表的连锁才有这个框,比较准。现在是麦当劳(麦当劳中国官网 2025 年 4 月版,76 道);肯德基的官方数据只在它的 APP 里,还没录,先当参考。
- **虚线框 + 食堂菜单**:选了食堂之后,每道菜的营养是食堂官方的,但一勺还是两勺是看图估的,所以区间中等。看到份数不对就改。
- **虚线框 + 参考数据·未核实**:连锁的数据还没逐行核实过,先当参考。
- **虚线框 + 目测估算**:食堂、家常菜、外卖的餐盘,是看图估的,区间最宽。
- 首页两个数:今天蛋白还差多少、本周预算还剩多少。只陈述事实,不会告诉你该吃什么。
- 首页的「下一顿」卡片:在你自己记过的餐和存过的菜单里,今天的钱够买的那些,按每块钱换多少蛋白排好,先显示三样,可以展开,点一下就记上。"今天还能花"是把本周剩下的预算摊到剩下的天数里算的。它只是把你吃过的东西排个序,选什么你自己定。
- **虚线框 + 食材表·未核实**:拍菜单时,蛋白是按"一只鸡腿、一个蛋、一碗饭"这样的食材表加出来的。这张表还没有逐行核对过,所以只当参考。
- **实线绿框 + 标签数据**:你自己照标签填的蛋白粉,一勺多少就是多少。
- **分/g** = 这份食物每克蛋白质花了多少分钱,越低越划算。周报里有你自己的排行榜。蛋白粉在排行榜下面单列一行,不和食物比。

## 6. 周报

底部「周报」:本周花销 vs 预算、蛋白达标天数、蛋白质单价排行榜、和上周的变化。可以往前翻。最下面能生成一张分享图,发群里或朋友圈都行。
周报里有一个问题:"这周有没有因为看到这些数字,换过一次吃的地方或点的东西?"点一下「换过」或「没换过」就行,怎么答都没关系,这是我判断这个工具有没有用的最重要的一个数。

## 7. 每周帮我做一件事

周日打开「设置」→「导出 JSON」,把文件发给我。里面只有你的记录和设置,没有照片。
这也是你的备份:数据只存在你手机浏览器里,**不要清 Safari / Chrome 的网站数据**,换手机前先导出。

## 8. 识别失败怎么办

照片太糊、不是食物、小票读不出来,会提示重拍或改用文字输入,不会卡住。实在不行就一句话写上。

有任何觉得别扭的地方直接在群里说,越具体越好(哪一步、截图)。
